# Сводка аудита — Maxvalpav/EfCoreInterceptors

Репозиторий: https://github.com/Maxvalpav/EfCoreInterceptors
Пакет: `EfCore.Interceptors` (EF Core 10, .NET 10, MIT)

## Что это

Набор из ~60 production-ready интерсепторов, покрывающих все 7 типов
интерсепторов EF Core: аудит, soft delete, доменные события и outbox,
логирование SQL, медленные запросы, кэш L2, детект N+1, query hints,
read-only guard, session init, транзакции, шифрование свойств,
identity resolution, метрики.

## Топ-5 к исправлению

1. **Query filter тенанта + кэш модели** — риск межтенантной утечки данных.
2. **Состояние, ключуемое по `DbContext`** — утечка памяти и гонки.
3. **Outbox без claim/lock** — двойная доставка при нескольких инстансах.
4. **Порядок интерсепторов не детерминирован** — тихие баги в аудите.
5. **`ConcurrencyRetry` внутри внешней транзакции** — повтор в мёртвой транзакции.
